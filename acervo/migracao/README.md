# migracao/ — Meta-processo do acervo pessoal

> **Esta pasta é um meta-processo de curadoria pessoal do coordenador — não é documentação da equipe.**

Os arquivos aqui registram o processo de triagem e destilação de notas do vault Obsidian pessoal em direção ao acervo. Não contêm padrões técnicos, decisões de plataforma nem documentação operacional.

## O que está aqui

| Arquivo | Propósito |
|---|---|
| `INVENTARIO_BRUTO.md` | Lista de notas do vault candidatas ao acervo, por categoria |
| `MATRIZ_CLASSIFICACAO.md` | Tabela origem → destino → ação → prioridade para cada candidata |
| `PLANO_PUBLICACAO_INCREMENTAL.md` | As 4 passadas do processo de curadoria, cadência e critério de entrada |
| `DOCUMENTOS_ESSENCIAIS_ACERVO.md` | Núcleo obrigatório de migração e complementares de alto valor |
| `SELECAO_NOTAS_PARA_MIGRACAO_2026-07-21.md` | Registro histórico do que foi migrado por rodada |
| `PROPOSTA_ENVIO_LAKEHOUSE_INMOV_2026-07-21.md` | Proposta formal de envio de itens ao acervo oficial da equipe (`lakehouse-inmov`) — aguardando revisão |

## Fluxo resumido

```
Vault Obsidian (maior) → INVENTARIO_BRUTO → MATRIZ_CLASSIFICACAO → PLANO_PUBLICACAO_INCREMENTAL → acervo/
                                                                                                      ↓
                                                                                        PROPOSTA_ENVIO → lakehouse-inmov (acervo oficial da equipe)
```

## Regra

Nenhum arquivo desta pasta deve ser referenciado como fonte de verdade por membros da equipe. Para documentação operacional, usar o `lakehouse-inmov`.
